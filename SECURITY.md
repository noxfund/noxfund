## 🚨 Reporting a Vulnerability

While the smart contract itself is immutable and cannot be changed, we appreciate responsible disclosure of any security concerns:

### For Smart Contract Issues:
1. **Email:** security@nox.fund
2. **Telegram:** [@noxfundchat](https://t.me/noxfundchat)
3. **Response Time:** We aim to respond within 48 hours

### What to Report:
- Potential vulnerabilities in the smart contract logic
- Issues with the frontend or website
- Phishing attempts or impersonation
- Security concerns with documentation or communications

### What to Include:
- Detailed description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact assessment
- Your recommended remediation (if any)

## ⚠️ Important Notice

**The smart contract is immutable and cannot be patched or upgraded.** However, we maintain the following for user safety:

- Frontend security updates
- Documentation accuracy
- Community awareness of potential risks
- Detection and reporting of scam/phishing sites

## 🔐 Best Practices for Users

1. **Verify Contract Address:** Always use the official contract address
2. **Use Official Website:** Only interact via [nox.fund](https://nox.fund)
3. **Check BSCScan:** Verify all transactions on [BSCScan](https://bscscan.com)
4. **Never Share Private Keys:** NoxFund team will NEVER ask for private keys
5. **Beware of Impersonators:** Verify all official communications
