Security Best Practices

Protect your funds and stay safe in DeFi

🚨 Critical Security Rule:
If someone asks for your seed phrase or private key, they are trying to scam you. NEVER share these with anyone, including NOX FUND "support" or "admins." There are no admins—the protocol is ownerless.

🛡️ Wallet Security

1. Seed Phrase Protection

Your 12-word seed phrase is the master key to your wallet. If someone has it, they own everything in your wallet.

CRITICAL

Best Practices:

  • Write it on paper, never store digitally
  • Keep multiple copies in secure locations
  • Never take photos of it
  • Don't share it with anyone, ever
  • Consider using a metal backup for fire protection
  • Test your backup by restoring wallet in test environment

2. Use Hardware Wallets for Large Amounts

If you're holding significant value, consider a hardware wallet:

  • Ledger Nano X/S Plus: Popular and user-friendly
  • Trezor Model T: Open-source option
  • Benefits: Private keys never leave device, resistant to malware

3. Enable Security Features

  • Use strong, unique password for wallet
  • Enable biometric authentication if available
  • Use password manager for secure storage
  • Enable 2FA where possible

🎣 Common Scams & How to Avoid Them

CRITICAL

1. Phishing Websites

Attack: Fake websites designed to steal your wallet info

Prevention:

  • Bookmark the real nox.fund URL
  • Always check URL before connecting wallet
  • Look for HTTPS and SSL certificate
  • Be wary of links in Telegram/Discord
  • Google may show fake ads—skip them
CRITICAL

2. Fake Support Scams

Attack: Someone impersonating admin/support asking for seed phrase

Prevention:

  • NOX FUND has NO admins or support staff
  • Never respond to DMs offering "help"
  • Real community members help in public channels only
  • Block and report anyone asking for private keys
HIGH

3. Approval Scams

Attack: Malicious contracts requesting unlimited token approval

Prevention:

  • Only approve exact amounts needed
  • Verify contract address on BSCScan
  • Revoke approvals after use (use revoke.cash)
  • Never sign transactions you don't understand
HIGH

4. Airdrop Scams

Attack: Unknown tokens sent to your wallet with instructions to claim

Prevention:

  • Never interact with unknown tokens
  • Don't visit links from random airdrops
  • These tokens are worthless and dangerous
  • Simply ignore them in your wallet

✅ Transaction Safety Checklist

Before confirming ANY transaction:

  • Verify you're on the correct website
  • Check the contract address matches official
  • Ensure you're on BNB Smart Chain (Chain ID: 56)
  • Review transaction details in wallet popup
  • Verify amounts and recipient addresses
  • Start with small test transaction if unsure

🚫 Red Flags - Immediate Warning Signs

🚨 SCAM INDICATORS

  • Asking for seed phrase
  • Promising guaranteed returns
  • Pressure to act immediately
  • Unsolicited DMs
  • Too-good-to-be-true offers
  • Spelling errors in URLs
  • Requests to install software

✅ LEGITIMATE BEHAVIOR

  • Transparent documentation
  • Open-source code
  • Public community channels
  • Clear risk disclosures
  • Verified smart contracts
  • No private support DMs
  • Educational resources

💻 Device & Browser Security

Computer Security

  • Keep operating system updated
  • Use reputable antivirus software
  • Don't use public/shared computers for crypto
  • Enable firewall protection
  • Be cautious with browser extensions

Mobile Security

  • Only download wallets from official stores
  • Keep your phone OS updated
  • Use screen lock with PIN/biometric
  • Avoid rooted/jailbroken devices
  • Don't install untrusted apps

Network Security

  • Avoid public WiFi for transactions
  • Use VPN for additional privacy
  • Secure your home router
  • Use HTTPS everywhere

📱 Telegram/Discord Safety

⚠️ Community Channel Safety:
  • Admins will NEVER DM you first
  • Disable DMs from non-contacts
  • Report and block scammers immediately
  • Verify usernames carefully (check for impersonators)
  • Don't click suspicious links
  • All official announcements are in public channels

🔍 How to Verify Smart Contracts

  1. Go to BSCScan: bscscan.com
  2. Search contract address: 0x433830E36585bdACC840E1caB419C4211bBf13f5
  3. Look for green checkmark (verified source code)
  4. Review "Contract" tab to see source code
  5. Check "Read Contract" for contract parameters
  6. Verify no owner/admin functions exist

💰 Risk Management

Investment Safety

  • Start Small: Test with minimum amount first
  • Diversify: Don't put all funds in one protocol
  • Only Risk What You Can Lose: Never invest emergency funds
  • Take Profits: Periodically withdraw earnings
  • Stay Informed: Monitor protocol health

Exit Strategy

  • Set profit targets and stick to them
  • Plan withdrawal schedule in advance
  • Keep some funds liquid for emergencies
  • Don't get emotionally attached to investments

🆘 What to Do If Compromised

If your wallet is compromised:
  1. Act Immediately: Every second counts
  2. Transfer Assets: Move funds to new clean wallet
  3. Create New Wallet: With new seed phrase
  4. Revoke Approvals: Use revoke.cash on old wallet
  5. Never Reuse: Abandon compromised wallet permanently
  6. Learn: Identify how breach occurred
