2. Technical Architecture

2.1 Smart Contract Design

The protocol is built on a single, non-upgradeable smart contract using Solidity ^0.8.24. Key architectural principles:

  • No Proxy Pattern: Direct implementation, no delegatecall vulnerabilities
  • Immutable Constants: All economic parameters are compile-time constants
  • Pull Payment Pattern: Users initiate all withdrawals (prevents forced transfers)
  • ReentrancyGuard: Protection against reentrancy attacks
  • SafeERC20: Safe token transfer operations

2.2 Data Structures

Deposit Structure

struct Deposit {
    uint128 principal;           // Original deposit amount

3.2 Capital Lock Mechanism

Principal is locked for 45 days from the deposit timestamp. This creates a rolling compound opportunity:

  • Days 1-45: Earn daily ROI, reinvest for compounding
  • Day 46+: Original principal unlocks, new deposits still earning
  • Strategy: Daily reinvestment creates staggered unlock schedule

3.3 Maximum ROI Cap

Each deposit can accumulate ROI for a maximum of 365 days, resulting in:

Maximum ROI per deposit: 1.5% × 365 days = 547.5%
After reaching this cap, the deposit stops accruing ROI but principal remains withdrawable.

6. Smart Contract Details

6.1 Core Functions

deposit(uint256 amount, string referralIdentifier)

Makes a new deposit with optional referrer:

  • Minimum: 1 USDT
  • Maximum deposits per user: 200
  • Referrer locked on first deposit
  • 5% fee sent to fee recipient
  • 20% referral commissions distributed

withdrawROI(uint256[] depositIndices)

Withdraws accumulated ROI from specified deposits:

  • Calculates days elapsed since last claim
  • Caps at 365 days total per deposit
  • Updates lastClaimTime
  • Transfers USDT to user

withdrawPrincipal(uint256[] depositIndices)

Withdraws unlocked principals:

  • Requires 45+ days since deposit
  • Also claims any pending ROI
  • Marks deposit as withdrawn
  • Transfers principal + ROI

withdrawReferralBalance()

Withdraws accumulated referral commissions:

  • Claims all pending referral earnings
  • Updates global tracking
  • Transfers USDT to user
